# Eureka OS

`os.eureka.pe.kr`용 레트로 데스크톱 스타일 AI 작업실 MVP입니다.

## Stack

- React
- TypeScript
- Vite
- CSS-only custom retro UI

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Notes

- Microsoft/Windows 및 Molroo와 무관한 독립 프로젝트입니다.
- 타사 로고/아이콘/폰트/효과음을 사용하지 않고 자체 브랜드/아이콘/테마로 구성했습니다.
- 배포 타깃은 정적 산출물 `dist/`입니다.
